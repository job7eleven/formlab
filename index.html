拍攝方式與注意事項
  1. 跑步：手機在跑步機正側面 2–3 公尺、腰部高度，全身入鏡。
  2. 引體向上：手機在正前方或側面，單槓與雙手都要在畫面內，腳也盡量入鏡。
  3. 棒球打擊：從一壘或三壘方向側拍，球棒揮動範圍要在畫面內；揮棒很快，建議用手機慢動作錄好，再用「設定 → 分析影片檔」。
  4. 打開輔助線，讓傾斜顯示綠色（±1° 內），人物高度佔畫面 55–85%。
  5. 前鏡頭畫面會鏡射顯示，但數據用原始畫面計算，左右是正確的。
  6. 本程式不錄影、不上傳：只保存關節座標。每次記錄會在手機「下載」資料夾存同名的 CSV 和 JSON 兩個檔。

參考範圍為一般常見值，僅供自我觀察，不構成教練或醫療建議。
